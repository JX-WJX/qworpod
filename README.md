Qworpod

A liquid glass capsule for Windows.

Features

Liquid glass UI

Time and CPU display

Click to expand, click outside to collapse

Draggable

System tray

Autostart toggle

Privacy

Fully offline. No network requests. No telemetry. No account. No cloud.

Build

npm install

npm run tauri icon your-icon.png

npm run tauri dev

npm run tauri build
