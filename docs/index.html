为什么我们坚持用最难的 C# 重写？

传统 Web 套壳挂件

  • ✕ 动辄 100MB+ 的安装包，塞满浏览器内核
  • ✕ 内存占用极高，开机自启拖慢系统
  • ✕ 圆角边缘经常出现黑色锯齿或灰边
  • ✕ 亚克力模糊形同虚设，只能靠模拟

Qworpod 原生方案

  • ✓ 仅 1.5MB 单文件，无需任何运行环境
  • ✓ 常驻内存几兆，纯正的极客体验
  • ✓ 底层 Win32 物理裁剪，边缘绝对完美
  • ✓ 原生 DWM API 直接调用，真正的液态玻璃
ARCHITECTURE

为什么不用 Web？

传统桌面挂件大多依赖网页套壳技术，导致内存占用高、渲染锯齿、甚至需要安装巨大的运行环境。

Qworpod 采用纯正的原生 C# 编写，调用底层的 GDI 与 Win32 API 进行物理区域裁剪（Region），配合 DWM 原生亚克力，在保证 60fps 动画的同时，把内存压榨到了极致。
