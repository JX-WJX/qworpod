ARCHITECTURE

为什么不用 Web？

传统桌面挂件大多依赖网页套壳技术，导致内存占用高、渲染锯齿、甚至需要安装巨大的运行环境。

Qworpod 采用纯正的原生 C# 编写，调用底层的 GDI 与 Win32 API 进行物理区域裁剪（Region），配合 DWM 原生亚克力，在保证 60fps 动画的同时，把内存压榨到了极致。

MainWindow.xaml.cs
protected override void OnSourceInitialized(EventArgs e)
{
base.OnSourceInitialized(e);
// 注入原生 DWM 背景与物理裁剪
DwmService.ApplyCornerPreference(_hwnd);
ApplyBackdropMode();
ClipNow();
}

常见问题

Qworpod 真的完全不需要联网吗？

是的。软件内部没有任何发起网络请求的代码，不使用云端服务，也没有任何遥测和账号系统。它就是一个纯粹的单机工具。

会收集我的硬件信息吗？

不会。所有的 CPU、内存数据都是通过 Windows 底层的 API 实时读取的，仅在本地内存中处理并显示在界面上，软件关闭即销毁。

需要安装 .NET 运行环境吗？

如果你下载的是单文件绿色版，则不需要安装任何额外环境，双击即可运行。如果你下载的是安装包，会自动处理所有依赖。
